# The model makes the forecast

Reckon's model receives a defined evidence snapshot and chooses a prediction and confidence, with permission to abstain. Deterministic rules validate its output and limit stakes, and the model cannot move money directly; the evidence and model response are recorded for inspection. This makes the model's judgment part of the experiment instead of using it only to decorate a statistical forecast, so unavailable inference produces no new prediction rather than an undisclosed substitute forecast.

Accepted by the user during the grill-with-docs interview on 13 November 2026, IST. Subsequent decisions constrain the question to whether the settlement price is strictly above the reference price, and limit evidence to recent market history, reference price, and the prediction and settlement rules. The exact data provider and model remain subject to feasibility checks. ADR 0003 records the subsequently accepted settlement observation rule.
